# Solace 1.0

Solace is a deliberately small OTClientV8 assistant designed for a human player
who wants useful safeguards without turning over every decision to a bot.

## Features

- configurable healing spell;
- configurable mana potion;
- food use from open containers;
- low-health alarm;
- newly visible player alarm and client taskbar flash.

All gameplay features start **disabled**. Select `Solace_1.0` in the Bot window,
enable the profile, configure the controls, and then enable only the individual
switches you want. Settings and switch states are stored by OTClientV8 in the
active client profile.

Item IDs and spell words vary between servers, so the defaults are intentionally
minimal. Drop the appropriate item from your server onto the mana-potion slot.

Always follow the rules of the game server on which you play.
